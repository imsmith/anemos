    Anemos.Runtime.DataModelRegistry (anemos v0.1.0)

    Copy Markdown View Source

    Agent mapping data model keyword strings to handler modules.

    Handler modules must implement the Anemos.DataModel behaviour and expose a keyword/0 function that returns their format identifier.
