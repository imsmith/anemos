    Anemos.Runtime.Interaction (anemos v0.1.0)

    Copy Markdown View Source

    The vocabulary shared by on <interaction> blocks and the host.

    A when takes a report: an event with a truth at the time it arrives, which stands until the next report of the same event and feeds compound triggers, dwell timers and conditions. An on takes an interaction: an occurrence with no truth, never remembered, fired once per occurrence. Boot, shutdown, a keypress, a login — things that happen, not claims about the world.

    Interactions travel the same index as events under names in the reserved ON_ namespace, which when may not subscribe to and dispatch/4 may not send. The compiler and the runtime both derive those names here so a host's interact(:rt, {:keypress, "ESC"}) meets the block compiled from on keypress "ESC".
