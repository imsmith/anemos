    Anemos.Runtime.Modes (anemos v0.1.0)

    Copy Markdown View Source

    Modes (PRD §3.13): named, runtime-wide, each active with a value or not active at all. [MODE::set "away"] makes away active with the value true, [MODE::set "level" 2] with the value 2, and [MODE::unset "away"] makes it inactive.

    it <mode> { ... } gates the triggers inside it on the mode holding, and as "<mode>" and by ... that run when theirs comes to hold. A modal reference is {mode, value}. It holds when the mode is active and, for a non-nil value, when the mode's value equals it.

    MODE is the runtime's own module, not a host one. Its state is the dispatcher's, so a change runs in statement position where the dispatcher can act on it. active and current may be read anywhere.
