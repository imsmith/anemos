    Anemos.Runtime.ModuleRegistry (anemos v0.1.0)

    Copy Markdown View Source

    Maps module names (e.g. "DEVICE", "FILE") to Elixir modules implementing the Anemos.Runtime.Module behaviour.

    Trust model

    This table decides where every [MODULE::verb ...] in every loaded policy executes. It is reachable by a documented public name (:"#{runtime_name}.registry"), so any process in the VM can address it. Registration is therefore write-once: binding a name that is already live is refused and logged, so a later register/3 cannot silently redirect "SECRET" or "INFRA" at a module of someone else's choosing while the policy continues to look normal from outside.

    Three outcomes:

    • name unbound — bound, logged at :info
    • name bound to the same module — idempotent :ok (host code and tests re-register defaults freely)
    • name bound to a different module — an anemos.runtime/already_registered error, logged at :warning, binding unchanged

    A deliberate rebind is still possible, but it has to say so: register(reg, name, module, replace: true). That path also logs at :warning, because a verb changing destination mid-flight is an event an operator should see either way.

    This raises the bar from "any process can rebind" to "any process can rebind loudly, and only by asking". It is not an authorization check — there is no caller identity to check against. A registry that must not be written by arbitrary code should not be given a public name.

    register(registry, name, module, opts \\ [])

    @spec register(pid() | atom(), String.t(), module(), keyword()) ::
  :ok | {:error, Comn.Errors.ErrorStruct.t()}

    Registers an Elixir module under the given name (e.g., "DEVICE").

    Write-once. Re-registering the same module is idempotent; binding a live name to a different module is refused unless replace: true is given. Every outcome is logged. See the module docs for the trust model.

    Options

    • :replace — when true, deliberately rebind a live name (default false)

    Examples

    iex> {:ok, reg} = Anemos.Runtime.ModuleRegistry.start_link([])
iex> Anemos.Runtime.ModuleRegistry.register(reg, "DEVICE", Anemos.Runtime.Modules.Device)
:ok
iex> {:error, error} =
...>   Anemos.Runtime.ModuleRegistry.register(reg, "DEVICE", Anemos.Runtime.Modules.File)
iex> error.code
"anemos.runtime/already_registered"

    start_link(opts)

    Starts a module registry.

    Options

    • :name — process registration name (optional)
    • :state_table — an Anemos.Runtime.StateTable the bindings are kept in, so that this process restarting does not lose them (A-43). Optional; without it a restarted registry is empty.
    • :modules — %{name => module} bound at start, under whatever the table remembers (optional)
