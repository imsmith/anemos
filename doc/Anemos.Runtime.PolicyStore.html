    Anemos.Runtime.PolicyStore (anemos v0.1.0)

    Copy Markdown View Source

    Durable record of everything that has been loaded into a runtime.

    The dispatcher holds a derived view — a rule index, a set of condition servers, a set of capability servers. That view is disposable. This store holds the source it is derived from, so that a dispatcher which crashes and is restarted by its supervisor can rebuild rather than come back blank.

    Without it, re-parenting the dispatcher's children (see Anemos.Runtime.StoreSupervisor) only narrows the window: any other dispatcher crash still produced a restarted dispatcher with rules: [], and dispatch/3 then returned {:ok, []} forever — byte-identical to "no rule matched".

    It also holds the channel connector, which is set through the dispatcher at runtime and would otherwise silently revert to the default on restart.

    drop_rules(store, rule_names)

    @spec drop_rules(Agent.agent(), [String.t()]) :: :ok

    Removes the named rules from every stored compilation result.

    This is what makes Anemos.Runtime.Dispatcher.unload/2 durable. The dispatcher's rule list is derived and rebuilt from this store on restart, so an unload that touched only the derived view would be undone by the next dispatcher crash — the rule would come back.

    Only rules are removed. A compilation result also carries conditions, capabilities and data blocks, which are not owned by any one rule and are not implied by unloading one. A result left with no rules is kept for the same reason.

    Options

    • :name — process registration name (optional)
    • :state_table — an Anemos.Runtime.StateTable the record is kept in. This store survives a dispatcher crash on its own; the table is what lets it survive its own restart, which the supervisor forces whenever a child ahead of it — the module registry, say — dies (optional)
