    Modules

    Anemos

    Anemos — event-driven automation DSL.

    Anemos.AST

    AST node structs for the Anemos DSL.

    Anemos.AST.At

    A time-triggered at block with a time spec, optional guard, and body.

    Anemos.AST.BinaryOp

    A binary operator expression.

    Anemos.AST.BlockArgs

    A block argument list of key-value pairs.

    Anemos.AST.BuiltinCall

    A built-in function call (filter, map, reduce, emit).

    Anemos.AST.Capability

    A named capability declaration with context, body, and source line.

    Anemos.AST.Command

    A module command expression with a verb and arguments.

    Anemos.AST.Condition

    A named condition declaration with a body and source line.

    Anemos.AST.Context

    A context scope block with a dotted path and body.

    Anemos.AST.DataDecl

    A named data declaration with content, optional source/transclude, scope, and source line.

    Anemos.AST.Demand

    A demand expression referencing a capability with a PAM-style control flag.

    Anemos.AST.Done

    A done statement: exits the current handler with no value.

    Anemos.AST.Emit

    An emit expression that produces a typed value to an optional destination.

    Anemos.AST.Flow

    A named flow declaration with a body and source line.

    Anemos.AST.For

    A for loop: iterates var over iterable, executing body each time. Covers for, each, every, foreach.

    Anemos.AST.If

    A conditional if block with an optional guard, body, and else branch.

    Anemos.AST.Introspect

    An introspection statement — show, list, graph, trace, explain, exists, infer, assert — or exists in expression position. The subject is a bare {:name, "NAME"}, a {:catalogue, :rules | :conditions | :modules | :events | :policies | :schedules}, or {:expr, expression}.

    Anemos.AST.It

    An it modal reference block.

    Anemos.AST.Let

    A let variable binding.

    Anemos.AST.ListLiteral

    A list literal expression.

    Anemos.AST.Literal

    A literal value node (string, integer, float, boolean, atom).

    Anemos.AST.Log

    A log expression.

    Anemos.AST.NextEvent

    A nextevent statement: transitions to another when block within the same rule, optionally carrying a with { } argument block (A-55).

    Anemos.AST.NextRule

    A nextrule statement: dispatches to a different rule's pipeline, optionally carrying a with { } argument block.

    Anemos.AST.On

    An on invocation block triggered by a named invocation.

    Anemos.AST.Program

    Top-level program node wrapping all parsed declarations.

    Anemos.AST.QueryDecl

    A named query declaration with expect/engine/body/return, scope, and source line.

    Anemos.AST.Return

    A return statement: exits the current handler, optionally with a value.

    Anemos.AST.Rule

    A named rule declaration with a body, optional metadata, and source line.

    Anemos.AST.Set

    A set variable assignment.

    Anemos.AST.SignedBy

    A source-level signed_by declaration (A-60).

    Anemos.AST.Triple

    An RDF-style triple with subject, predicate, and object.

    Anemos.AST.UnaryOp

    A unary operator expression.

    Anemos.AST.VarRef

    A variable reference with an optional sigil prefix.

    Anemos.AST.When

    A when trigger block: fires on an event, with optional duration, guard, and body.

    Anemos.AST.While

    A while loop: repeats body while condition is truthy.

    Anemos.Application

    OTP application callback for Anemos. Starts no interpreter.

    Anemos.Channel

    Behaviour for channel connectors — the bridge between Anemos emit operations and the host app's messaging infrastructure.

    Anemos.Channel.ComnBus

    Channel connector that publishes envelopes via Comn.EventBus.

    Anemos.Channel.Logger

    Default channel connector that logs emitted messages via Logger.info/1.

    Anemos.CompilationResult

    Result of compiling an Anemos program.

    Anemos.CompiledCapability

    A compiled capability: name, context scope, and handler closure for on-demand execution.

    Anemos.CompiledCondition

    A compiled condition: name, trigger subscriptions, evaluator function, and side effects.

    Anemos.CompiledData

    A compiled data block.

    Anemos.CompiledQuery

    A compiled query block.

    Anemos.CompiledRule

    A compiled rule: name, event subscriptions, handler closure, and optional dwell duration.

    Anemos.CompiledSchedule

    A compiled schedule: event name, time spec, recurrence, and handler.

    Anemos.Compiler

    Walks the AST produced by Anemos.Parser and produces %Anemos.CompiledRule{}, %Anemos.CompiledCondition{}, and %Anemos.CompiledCapability{} structs with executable closures. No code generation, no Module.create.

    Anemos.DataModel

    Behaviour for pluggable data format and query engine handlers.

    Anemos.Envelope

    Message envelope for emitted values.

    Anemos.Event

    Protocol for types that can be dispatched as Anemos events.

    Anemos.Lexer

    NimbleParsec-based tokenizer for the Anemos DSL.

    Anemos.Module

    Macro for defining Anemos modules — named sets of verb handlers.

    Anemos.Parser

    Recursive descent parser for the Anemos DSL.

    Anemos.Redact

    Shape summaries for values that must be observable without being disclosed.

    Anemos.Runtime

    Supervisable runtime interpreter for Anemos policies.

    Anemos.Runtime.ArgSchema

    Validates the arguments of a [MODULE::verb ...] command before they reach a host module.

    Anemos.Runtime.Builtins

    Built-in collection-processing functions for pipeline expressions.

    Anemos.Runtime.CapabilityServer

    GenServer for a single named capability. Passive until demanded. Executes its on demand handler and returns the result.

    Anemos.Runtime.ConditionServer

    GenServer for a single named condition. Holds boolean state. Evaluates incoming events against trigger logic. Broadcasts CONDITION_<name> on false->true transition. Queryable for current state at any time.

    Anemos.Runtime.ContextScope

    The one comparison that decides whether one context path lies inside another.

    Anemos.Runtime.ContextStore

    Agent holding external key-value context data. Keys are dotted paths (e.g., "infra.networking.dns.fqdn"). Resolution joins the context path with the variable name to form the lookup key.

    Anemos.Runtime.DataModelRegistry

    Agent mapping data model keyword strings to handler modules.

    Anemos.Runtime.DataStore

    GenServer holding named datasets for data blocks.

    Anemos.Runtime.Demand

    Evaluates a stack of demand operations against capability servers using PAM-style control flag semantics.

    Anemos.Runtime.Dispatcher

    GenServer holding compiled rules indexed by subscription.

    Anemos.Runtime.Duration

    Converts duration tuples (e.g., {5, :min}) to milliseconds.

    Anemos.Runtime.Errors

    Compile-time error code registry for the Anemos runtime.

    Anemos.Runtime.Introspection

    Answers the introspection statements — show, list, graph, trace, explain, exists, infer — from the dispatcher's state.

    Anemos.Runtime.LoadAuthority

    The trust boundary on loading policy (A-12).

    Anemos.Runtime.LoadAuthority.Denied

    Refuses every load.

    Anemos.Runtime.LoadAuthority.Permissive

    The default authority: grants every load.

    Anemos.Runtime.LoadAuthority.Signed

    A load authority that verifies detached Ed25519 signatures over the policy source (A-05).

    Anemos.Runtime.LoadRequest

    Everything an Anemos.Runtime.LoadAuthority gets to decide on.

    Anemos.Runtime.Module

    Behaviour for Anemos runtime modules (DEVICE, FILE, etc.).

    Anemos.Runtime.ModuleRegistry

    Maps module names (e.g. "DEVICE", "FILE") to Elixir modules implementing the Anemos.Runtime.Module behaviour.

    Anemos.Runtime.Modules.Device

    Stub DEVICE module for development and testing.

    Anemos.Runtime.Modules.Example

    Demonstration doubles for the module verbs used by priv/examples/.

    Anemos.Runtime.Modules.Example.Event

    EVENT double. Verb names are dotted event names (ip.addr.changed), so handle_verb/3 accepts any verb and echoes it rather than enumerating a fixed list.

    Anemos.Runtime.Modules.Example.File

    FILE double that answers extension from the path under evaluation.

    Anemos.Runtime.Modules.Example.Infra

    INFRA double for ddns.rule.

    Anemos.Runtime.Modules.Example.Pdf

    PDF double distinguishing document content from stored metadata.

    Anemos.Runtime.Modules.Example.Secret

    SECRET double that deliberately yields nothing usable.

    Anemos.Runtime.Modules.Example.String

    STRING double. slugify is a genuine pure function, not a stand-in — there is nothing to fake about lowercasing and hyphenating a string.

    Anemos.Runtime.Modules.File

    Stub FILE module for development and testing.

    Anemos.Runtime.Modules.Policy

    [POLICY::unload "id"] — a policy that removes another.

    Anemos.Runtime.NLD

    Natural Language Date resolver.

    Anemos.Runtime.PathGuard

    Confines a caller-supplied path to a configured root.

    Anemos.Runtime.PolicyStore

    Durable record of everything that has been loaded into a runtime.

    Anemos.Runtime.Report

    What an event reports, and what a compound trigger makes of the reports it has heard (A-47).

    Anemos.Runtime.RuleSupervisor

    Second supervision tier: rule-scoped processes.

    Anemos.Runtime.Scheduler

    GenServer that manages time-triggered schedules.

    Anemos.Runtime.Standalone

    Wires a dispatcher and its stores together outside a full Anemos.Runtime tree.

    Anemos.Runtime.StateTable

    Where a runtime keeps what its processes have accumulated, so that the restart of one of them does not lose it.

    Anemos.Runtime.StoreSupervisor

    Supervisor for stores-as-infrastructure.

    Anemos.Runtime.SubscribableRegistry

    Agent mapping protocol strings to Anemos.Subscribable handler modules.

    Anemos.Runtime.TripleStore

    Agent-based triple store for RDF-like facts.

    Anemos.Runtime.TrustStore

    Per-runtime trust configuration: a keyring of public verification keys, and the policy for sources that declare no signer at all (A-05).

    Anemos.Runtime.Watcher

    Keeps a directory of *.rule files deployed into a runtime.

    Anemos.Secret

    A wrapper for secret-bearing values that refuses to disclose itself.

    Anemos.Subscribable

    Behaviour for data sources that support dynamic subscription.

    Mix Tasks
