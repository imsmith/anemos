    Glossary

    Binding. A name associated with a value. A let creates an @ binding; a set creates a $ binding. See values.

    Capability. A passive named on demand body. Its context restricts which declaration may demand it. Current dispatch has important stack/execution limits. See capabilities.

    Channel. A named output destination handled by the current host connector. It is distinct from an internal event subscription. See channels.

    Command. A bracketed module/verb invocation. In value position it executes during evaluation; in statement position it becomes a queued operation. See operation order.

    Compound. The collection formed by value-level AND, preserving operand boundaries. See compounding.

    Compound trigger. A remembered-state AND or OR over event reports. It differs from value-level compounding. See reports.

    Condition. A named boolean state reevaluated on subscribed events. Its false-to-true transition generates CONDITION_<name> and evaluates transition actions. See conditions.

    Context data. Values available to ? lookup from the current dispatch's payload map. The host can merge defaults into that map. See event input.

    Context path. A dotted location used for listener and capability boundary checks. Whole segments determine containment. See boundaries.

    Dataset. Named reference data used for exact membership or read through ?name. Simple datasets are sets. See datasets.

    Declaration. A top-level named language definition, such as a rule or query. See source structure.

    Dispatch. Delivering an event through subscription selection, context filtering, handler evaluation, and operation execution. See execution model.

    Dwell. A duration for which a reported trigger state must remain true before a handler runs. See dwell timers.

    Envelope. A published value plus type, source, time, label, and channel. See emission.

    Event. An exact name, optional context path, and payload supplied by a producer. A name such as SENSOR::motion is still an event until bracketed as a command. See names.

    Falsey. Boolean false or host nil. All other values, including zero and empty collections, are truthy. See truth.

    Guard. A trigger/block modifier such as unless, evaluated before its body. See guards.

    Handler. The executable body selected for a trigger. Several handlers may belong to one named rule and share its persistent binding state.

    Host. The Elixir application embedding Anemos, supplying command modules, event producers, adapters, and operational guarantees. See embedding.

    Load authority. Host policy that admits/refuses source before compilation and installation. See authorization.

    Module. A registered collection of host verbs, addressed by a name such as MATH. It is not defined in policy source. See extension.

    Operation. A descriptor produced during body evaluation for the dispatcher to execute or report. Not every evaluated expression produces an operation.

    Partial load. A source installed with some inert declarations, reported as {:partial, failures}. See load outcomes.

    Payload. The data accompanying an event; normally a map with string keys.

    Persistent binding. A $ value retained across firings of one named rule, within the runtime's lifetime. See state.

    Pipeline. An expression passing a collection/value through |> stages. See pipelines.

    Policy. A source unit containing declarations. Named deployments give it an ID used for replacement and unload. See deployment.

    Query. A named host-engine computation invoked through ?name, with expected inputs and a named output. See queries.

    Report. An event's last true/false state remembered by a compound listener. It remains until replaced by a new report of the same event.

    Rule. A named collection of event/time handlers, context, state, and optional local data/query declarations. See first policy.

    Runtime. A supervised interpreter with installed policies, registered host modules, in-memory state, dispatcher, and scheduler.

    Sigil. A prefix (?, @, $) selecting how a value name is read.

    Transclusion. A data declaration's request to derive another representation; the handler performs it with transduce/3. See structured data.

    Triple. A subject–predicate–object fact stored in the runtime's shared triple store. See facts.

    Verb. An operation name implemented by a host module, such as double in MATH::double.
